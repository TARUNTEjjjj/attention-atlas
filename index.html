00 / THE BIG PICTURE

One question.
Three ways to connect.

Which parts of the input should influence the output?

A CNN looks nearby. An RNN carries a state forward. Attention lets positions exchange information directly. The difference is a pattern of computation you can see and calculate.

Start with addition, multiplication and vectors. We’ll build the rest together. Each lab uses small, fixed examples so you can verify every result.
